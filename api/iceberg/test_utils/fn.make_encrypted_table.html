pub async fn make_encrypted_table() -> Table
Expand description

Build a table backed by the V3 encryption fixture and an in-memory KMS, so it has an EncryptionManager.

The fixture’s snapshot references an encrypted manifest list; its bytes (the manifest-list-v3-encrypted.avro testdata, an encrypted empty list) are seeded into the in-memory FileIO at that path so callers can read the current snapshot’s manifest list.
