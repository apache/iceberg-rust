Function read_manifest_list

pub fn read_manifest_list(bytes: &[u8]) -> Result<RecordBatch>
Expand description

Reads the entries of a manifest list into a [RecordBatch] with one row per manifest.

The schema is the spec’s manifest_file struct for the latest format version, with field IDs in the Arrow field metadata, so manifest lists of every format version read into the same schema. Fields are matched to the manifest list’s Avro schema by field ID. The format version comes from the format-version key that writers put in the file’s metadata, and a manifest list without one is v1. A v1 manifest list reads with the spec’s v2+ defaults. Partition summary bounds keep the binary single-value serialization they were written with.

§Example

use iceberg::arrow::read_manifest_list;

let bytes = std::fs::read(concat!(
    env!("CARGO_MANIFEST_DIR"),
    "/testdata/manifests_lists/manifest-list-v2-2.avro"
))?;
let batch = read_manifest_list(&bytes)?;
assert_eq!(batch.num_rows(), 1);
