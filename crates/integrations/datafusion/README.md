# Apache Iceberg DataFusion Integration

This crate contains the integration of Apache DataFusion and Apache Iceberg.

## Moved to Apache DataFusion

The 0.11.x releases are the last releases of `iceberg-datafusion` from the Apache Iceberg project.
Following votes by the [Apache Iceberg](https://lists.apache.org/thread/ytb9x7x8ff3b7031kcrc05nzjtmh091s)
and [Apache DataFusion](https://lists.apache.org/thread/6k5lws31c61y1lx2s34pxo4lmc7334lr) communities,
future releases are maintained by the Apache DataFusion project at
[apache/datafusion-iceberg](https://github.com/apache/datafusion-iceberg), which has the source code,
the issue tracker, and install instructions for later versions.
